# The Credit Lane

CA, CS and Advocate-led corporate finance desk. We help Indian companies structure and secure the optimal mix of debt, equity, and government subsidies.

## Features
- **12 Loan Structures**: Complete eligibility checklists and financial parameters for business capital, SIDBI machine schemes, construction lines, NPA resolutions, and venture debt.
- **4 Equity Structures**: Valuation services, Pre-IPO listings, SME listings, and Mainboard IPOs.
- **3 Government Incentives**: Uttar Pradesh capital policies, MSME schemes, and MSMY policies.
- **Interactive Calculators**: Custom EMI, OTS settlement savings, share dilution, and UP subsidy eligibility calculators built-in.
- **GSAP reveals**: Smooth animation sequences driven by ScrollTrigger.

## Tech Stack
- **Structure & Layout**: Semantic HTML5 / Vanilla CSS3 / JavaScript
- **Animations**: GSAP (GreenSock Animation Platform) & ScrollTrigger
- **Build compiler**: Python 3 Static Site Builder (`build.py`)
